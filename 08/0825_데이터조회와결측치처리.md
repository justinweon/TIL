# 0825 TIL — 데이터 조회와 결측치 처리에서 머신러닝의 기초까지

데이터를 모델에 넣기 전에, 어떤 행을 보고 있는지와 비어 있는 값이 무엇을 뜻하는지부터 알아야 해요. 이날 노트는 pandas로 데이터를 살펴보고 정리하는 과정에서 출발해, 시각화와 머신러닝의 기본 개념으로 이어집니다.

## 1. 이름으로 고를지, 위치로 고를지 정하기

`DataFrame`은 행과 열에 이름이 붙은 표예요. pandas는 NumPy와 밀접하게 연동되지만, 라벨 정렬과 결측치 자료형처럼 배열만으로는 다루기 번거로운 기능도 제공합니다.

`loc`는 라벨로, `iloc`는 정수 위치로 데이터를 골라요. 인덱스 라벨이 숫자여도 이 차이는 유지됩니다. `df.loc[0]`은 이름이 `0`인 행이고, `df.iloc[0]`은 첫 행이에요.

아래는 원문의 학생 표와 조회 코드를 연결한 예시입니다. 코드 사이에 섞여 있던 출력 표와 구분선은 실행 코드에서 분리했어요. 예시는 실행 결과를 새로 확인한 기록이 아닙니다.

```python
import numpy as np
import pandas as pd

df = pd.DataFrame(
    {
        'age': [25, 30, 35, 40],
        'score': [80, 95, 70, 85],
        'grades': ['B', 'A', 'C', 'B'],
    },
    index=['user1', 'user2', 'user3', 'user4'],
)

user1 = df.loc['user1']
selected = df.loc['user1':'user3', ['grades', 'score']]
first_two = df.iloc[0:2, 0:3]
```

`loc['user1':'user3']`는 종료 라벨인 `user3`도 포함하지만, `iloc[0:2]`는 위치 `2`를 제외해요. 원문 출력의 `ser3`는 `user3` 오타로 바로잡았습니다.

| 하고 싶은 일 | 표현 |
|---|---|
| 모든 행에서 특정 열 선택 | `df.loc[:, ['age', 'score']]` |
| 여러 행과 열을 이름으로 선택 | `df.loc[['user1', 'user3'], ['age', 'grades']]` |
| 한 행씩 건너뛰기 | `df.iloc[::2, :]` |
| 마지막 행의 마지막 값 | `df.iloc[-1, -1]` |
| 단일 값 접근 | `df.at['user1', 'score']`, `df.iat[0, 1]` |
| 함수로 조건 전달 | `df.loc[lambda d: d['score'] > 80]` |

없는 라벨을 단일 선택하면 `KeyError`, 범위를 벗어난 정수 위치를 단일 선택하면 `IndexError`가 날 수 있어요. 다만 슬라이스는 끝이 범위를 벗어나도 잘려서 처리되는 경우가 있으므로 단일 선택과 구분합니다. `loc`로 `Series`를 대입할 때는 물리적 순서가 아니라 인덱스 라벨에 맞춰 정렬된다는 점도 기억해요.

## 2. 조건으로 필요한 행을 좁히기

불리언 인덱싱은 각 행에 대해 조건을 계산한 뒤 `True`인 행만 남기는 방식이에요. 여러 조건을 연결할 때는 원소별 연산자인 `&`와 `|`를 쓰고 각 조건을 괄호로 감쌉니다. 일반 파이썬의 `and`, `or`를 `Series`에 그대로 쓰는 것과는 달라요.

```python
older = df[df['age'] >= 30]
mask = (df['age'] >= 30) & (df['score'] >= 80)
selected = df.loc[mask]
selected_by_query = df.query('age >= 30 and score >= 80')
positions = np.where(df['age'] > 25)[0]
selected_by_position = df.iloc[positions]

# 원본의 값을 바꿀 때는 조건과 열을 한 번에 지정합니다.
df.loc[df['score'] < 50, 'status'] = 'Fail'
```

`query()` 안에서는 문자열 식의 `and`를 사용할 수 있어요. 반면 `df[mask]['score'] = ...`처럼 선택을 연달아 하는 대입은 원본 수정이 보장되지 않아 피합니다. 원문에 제목으로만 등장한 Copy-on-Write(CoW)도 이 문제와 연결돼요. 공유 데이터를 수정할 때 복사를 분리하는 동작이며, pandas 버전과 설정에 따라 세부 동작이 달라질 수 있습니다. 원본을 수정하려는 의도를 `df.loc[mask, col] = value`로 명확히 적는 편이 안전해요.

## 3. 결측치는 먼저 찾고, 의미에 맞게 처리하기

비어 있는 값을 모두 같은 방식으로 채우면 데이터의 뜻을 바꿀 수 있어요. 온도 기록 중간의 공백과 설문 미응답은 발생한 이유가 다르니까요. `info()`로 자료형과 유효값 수를 확인하고, `describe()`로 분포를 살펴본 뒤 처리 방법을 정합니다.

```python
raw_df = pd.DataFrame({
    'A': [1, np.nan, 3],
    'B': [pd.NA, 5, 6],
    'C': [7, 8, 9],
})
raw_df.info()
missing_per_column = raw_df.isna().sum()
missing_per_row = raw_df.isna().sum(axis=1)
missing_percent = raw_df.isna().mean() * 100
```

> 정정: `isna().sum(axis=0)`은 행 방향으로 합산하여 **열별 결측치 수**를 만들고, `axis=1`은 **행별 결측치 수**를 만듭니다. 원문의 축 설명이 반대로 읽힐 수 있어 구분했어요. 파이썬의 결측 표현은 `NONE`이 아니라 `None`입니다.

| 원문에서 다룬 처리 방법 | 사용할 때의 판단 |
|---|---|
| 탐색: `isna()`, `isnull()`, `notna()`, `notnull()` | 결측 위치와 비율을 먼저 확인해요. |
| 삭제: `dropna()` | 삭제할 행·열과 정보 손실을 함께 판단해요. |
| 대표값 대치: `fillna()` | 평균·중앙값·상수 또는 열별 사전을 사용할 수 있어요. 중앙값은 극단값의 영향을 덜 받습니다. |
| 직전·직후 값 대치: `ffill()`, `bfill()` | 정렬 순서와 값이 지속된다는 가정이 필요해요. |
| 보간: `interpolate()` | 관측 사이를 어떻게 연결할지 가정해요. |
| 이상 기호 치환·형 변환 | 결측 표시용 기호와 실제 측정값을 구분해요. |
| 결측 지표 만들기 | 누락 여부 자체가 정보를 줄 때 함께 보존해요. |

```python
rows_without_missing = raw_df.dropna()
columns_without_missing = raw_df.dropna(axis=1)
not_all_missing = raw_df.dropna(how='all')
enough_observations = raw_df.dropna(thresh=3)

# 중앙값 대치
age_df = pd.DataFrame({'age': [20, 25, None, 30, 95]})
median_val = age_df['age'].median()
age_df['age'] = age_df['age'].fillna(median_val)

# 순서가 있는 관측값의 대치와 보간
ts_df = pd.DataFrame({'온도': [18.2, None, None, 21.0]})
forward_filled = ts_df.ffill()
backward_filled = ts_df.bfill()
speed_df = pd.DataFrame({'속도': [10.0, None, None, 40.0]})
speed_df['속도'] = speed_df['속도'].interpolate(method='linear')

# 이 설문에서 -999와 ?가 미응답 표시라는 전제입니다.
survey_df = pd.DataFrame({'점수': [85, -999, '?', 95]})
survey_df['점수'] = survey_df['점수'].replace([-999, '?'], pd.NA)
survey_df['점수'] = pd.to_numeric(survey_df['점수'], errors='coerce')
survey_df.info()
survey_summary = survey_df.describe()

user_df = pd.DataFrame({'소득': [300, None, 450, None]})
user_df['미응답여부'] = user_df['소득'].isna()
```

`linear` 보간은 스스로 숨은 규칙을 발견하는 학습 알고리즘이 아니에요. 기본적으로 행 간격을 같은 것으로 보고 유효값 사이를 직선으로 잇습니다. 실제 시간 간격이 불규칙하면 그 간격을 반영하는 방법인지 따로 확인해야 해요. `bfill()`이나 양쪽 관측을 쓰는 보간은 미래 값을 참조할 수 있으므로 미래 예측에 그대로 적용하면 누수가 생길 수 있습니다.

`object`라는 이유만으로 모든 통계 연산이 불가능한 것은 아니지만, 숫자와 문자가 섞인 열을 수치 분석에 쓰기 전에는 명시적인 변환이 필요해요. `errors='coerce'`는 변환할 수 없는 값을 결측치로 바꾸므로 새로 생긴 결측도 확인합니다. `-999` 역시 항상 이상치는 아니며 데이터 명세에 따라 판단해요.

`np.nan == np.nan`으로 결측을 찾지 말고 `isna()`를 사용합니다. 일반 정수 열은 결측이 들어오면 실수형으로 바뀔 수 있지만, nullable 정수형인 `Int64`는 `pd.NA`를 담을 수 있어요. 원문의 “`inplace=True` 사용 중단”은 모든 해당 API가 폐기됐다는 뜻으로 일반화하지 않고, 반환값을 명시적으로 재대입하자는 코딩 습관으로 정리합니다.

머신러닝에서는 평균이나 중앙값도 데이터에서 학습한 값이에요. 분할을 먼저 하고 훈련 세트에서만 대치 기준을 구한 뒤 검증·테스트 세트에 적용해야 합니다.

## 4. 중복을 정리하고 그룹별로 비교하기

결측을 정리한 뒤에는 같은 관측이 중복되어 특정 패턴의 비중을 키우지 않는지 살펴봐요. 다만 값이 같다고 항상 잘못된 중복은 아니므로 관측 단위를 먼저 정합니다.

```python
duplicated_rows = df.duplicated()
df = df.drop_duplicates().reset_index(drop=True)
remaining_duplicates = df.duplicated().sum()

sales_df = pd.DataFrame({
    '지점': ['서울', '서울', '부산', '부산'],
    '매출': [100, 150, 80, 120],
})
grouped_df = sales_df.groupby('지점').mean(numeric_only=True)
sales_array = sales_df['매출'].to_numpy(dtype=np.float64)
```

`drop_duplicates()`는 남은 인덱스 번호를 자동으로 새로 매기지 않아요. `reset_index(drop=True)`를 이어 쓰면 기존 인덱스를 열로 보존하지 않고 다시 매깁니다. `groupby()`는 그룹 키가 결측인 행을 기본적으로 제외하므로 그 그룹도 필요하다면 `dropna=False`를 지정해요. `numeric_only=True`는 숫자 열만 집계하는 선택이지 문자 숫자를 자동 변환하는 옵션은 아닙니다.

## 5. 표에서 놓치기 쉬운 패턴을 그림으로 보기

시각화는 어떤 모델을 고를지에 앞서 데이터의 형태를 확인하는 데 도움이 돼요. Matplotlib은 NumPy·pandas와 함께 사용할 수 있고, 정적 그림뿐 아니라 애니메이션과 대화형 시각화도 지원합니다. PDF·SVG 같은 벡터 형식과 PNG·JPEG 같은 이미지 형식으로 저장할 수 있어요.

| 그림 | 확인하려는 것 |
|---|---|
| 산점도: `scatter()` | 두 수치 변수의 관계, 군집과 특이점 |
| 꺾은선: `plot()` | 시간이나 순서에 따른 추세, 계절성, 변동 |
| 히스토그램: `hist()` | 한 수치 변수의 구간별 빈도, 치우침과 봉우리 |
| 박스플롯: `boxplot()` | 중앙값, 사분위범위, 수염 바깥의 관측값 |

박스플롯의 `IQR`은 `Q3 - Q1`이에요. 기본적인 수염은 `Q1 - 1.5 × IQR`과 `Q3 + 1.5 × IQR` 안쪽의 관측값까지 그려집니다. 바깥 점은 확인할 후보이지 자동으로 삭제할 오류는 아니에요. 박스플롯은 범주 간 비교에도 쓰지만 하나의 수치 변수만으로도 그릴 수 있습니다.

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(6, 4), dpi=100, layout='constrained')
ax.scatter(df['age'], df['score'])
ax.set_xlabel('나이')
ax.set_ylabel('점수')
ax.set_title('나이와 점수의 관계')
# 한글 표시는 실행 환경의 한글 글꼴 설정이 필요할 수 있습니다.
```

위 코드는 원문의 깨진 `figsize` 문법을 보완해 구성한 설명용 예시예요. `figsize=(가로, 세로)`의 단위는 인치이고 `dpi`는 픽셀 밀도입니다. `Figure`는 전체 그림, `Axes`는 개별 좌표 영역이에요. 여러 패널은 `plt.subplots(r, c)`로, 복잡한 배치는 `GridSpec`으로 구성할 수 있습니다. `fig.suptitle()`은 전체 제목, `ax.set_title()`은 패널 제목을 설정해요.

원문에 보이는 추가 기능은 `fig.patch.set_facecolor()`의 배경색, `ax.inset_axes()`의 삽입 그림, 축의 `set_major_locator()`·`set_major_formatter()`를 통한 눈금 간격·표시 형식 조정, `ax.set_xscale('log')`, `fig.colorbar(im, ax=ax)`, `fig.legend()`예요. 이 중 `im`은 실제로 그린 색상 매핑 객체가 있어야 사용합니다.

## 6. 데이터에서 규칙을 배우는 방법

머신러닝은 데이터를 이용해 예측이나 의사결정에 필요한 규칙을 학습하는 방법이에요. 지도학습은 입력과 정답으로 회귀·분류를 배우고, 비지도학습은 정답 없이 군집이나 연관 구조를 찾습니다. 준지도학습은 라벨이 있는 데이터와 없는 데이터를 함께 활용하며, 강화학습은 행동에 따른 보상을 바탕으로 정책을 학습해요.

> 정정: 강아지 사진만 준 비지도학습이 스스로 인간의 단어인 “강아지”까지 알아낸다고 볼 수는 없어요. 비슷한 특징을 묶는 것과 그 묶음에 의미 있는 이름을 붙이는 일은 다릅니다. 또 `regression`은 회귀 전체를 뜻하고, 선형회귀는 그중 한 종류예요.

원문의 강한 AI·약한 AI 구분은 사람 수준의 범용 지능을 지향하는 개념과 특정 과업에 한정된 시스템의 대비로 이해합니다. 강한 AI의 정의와 성취 여부에는 논의가 있으므로 단정적인 현재 상태 판단은 덧붙이지 않아요.

알고리즘으로는 KNN, SVM, 결정트리, 앙상블과 인공신경망(ANN)이 소개됐어요. DNN은 깊은 신경망을 가리키며, CNN·RNN·GAN이 차례로 이전 것을 대체하는 일직선의 발전 단계는 아닙니다. CNN은 공간적 패턴에, RNN은 순서에 초점을 두고, GAN은 생성자와 판별자의 경쟁을 활용해요. 원문의 `LST`, `GRN`은 문맥에 맞게 `LSTM`, `GRU`로 고칩니다.

원문에 적힌 역사적 흐름도 구분해 둡니다. Rosenblatt의 퍼셉트론, Rumelhart·Hinton·Williams의 역전파 대중화, Fukushima의 Neocognitron과 LeCun의 CNN·LeNet 연구, Hopfield의 순환 구조와 Elman RNN, Hochreiter·Schmidhuber의 LSTM, Cho 등의 GRU, AlexNet의 이미지 인식 성과, Goodfellow 등의 GAN이 연결되어 있어요. 원문의 연도 범위는 여러 연구를 함께 묶은 요약이므로 특정 구조가 그 기간 내내 같은 이름으로 존재했다는 뜻으로 옮기지 않았습니다. 개별 역사적 연도는 외부 검증하지 않았어요.

## 7. 평균만으로 부족할 때 분산과 표준편차 보기

평균은 값의 합을 개수로 나눈 대표값이에요. 그러나 평균이 같아도 값들이 얼마나 흩어져 있는지는 다를 수 있습니다. 평균에서 뺀 편차를 그냥 더하면 양수와 음수가 상쇄되므로, 분산에서는 편차를 제곱해서 평균냅니다.

모집단 분산은 제곱편차 합을 관측 수로 나누고, 통상적인 불편 표본분산은 관측 수에서 하나를 뺀 값으로 나눠요. 분산의 단위는 원래 단위의 제곱입니다. 표준편차는 분산의 제곱근이라 원래 단위로 퍼짐을 해석할 수 있어요. 표준편차를 각 관측의 실제 거리나 평균 절대편차와 동일시하지는 않습니다.
