## 1. 원하는 답을 얻으려면 요청의 조건부터 정리해요

모델에 같은 주제를 물어도 목적, 배경, 출력 형식이 달라지면 필요한 답도 달라집니다. 프롬프트 기법은 이런 조건을 더 잘 전달하기 위한 방법이에요. 모델이 사용자의 상황을 모두 알고 있다고 가정하기보다, 필요한 정보를 적어 주는 데서 시작할 수 있습니다.

| 기법 | 전달하는 정보와 쓰임 |
| --- | --- |
| Zero-shot prompting | 예시 없이 지시로 작업을 요청해요. 간단하지만 형식이 흔들릴 수 있어요. |
| Few-shot prompting | 원하는 입출력 예시를 몇 개 제공해 형식과 작업 기준을 보여 줍니다. |
| Role prompting | 독자, 관점, 설명 수준에 맞는 역할을 지정해요. |
| Zero-shot CoT | 중간 절차를 고려하며 문제를 풀도록 요청하는 방식이에요. 검토 가능한 풀이 요약을 요구할 수 있습니다. |
| Few-shot CoT | 풀이 절차가 포함된 예시를 제공해 비슷한 문제 접근을 유도해요. |
| Step-back prompting | 구체적인 질문을 풀기 전에 관련 상위 원리와 배경 개념을 정리하도록 해요. |

Step-back 방식은 질문을 받은 뒤 필요한 원리를 도출하고, 그 원리와 원래 질문을 함께 사용해 답하는 흐름으로 이해할 수 있어요. 다만 모델이 도출한 배경지식도 틀릴 수 있으므로 신뢰할 수 있는 자료와 대조해야 합니다.

> 정정: LLM의 생성은 “가장 유사한 토큰을 고르는 검색”만으로 설명할 수 없어요. 문맥을 처리해 다음 토큰의 확률 분포를 계산합니다. 역할을 부여한다고 실제 전문가 자격이나 정확성이 생기는 것도 아닙니다. CoT나 step-back도 추론 정확도를 항상 높이거나 환각을 방지한다고 보장할 수 없어요. 출력된 풀이가 내부 계산 과정을 그대로 공개한 기록이라고 간주해서도 안 됩니다.

## 2. RTCCF로 빠진 조건 찾기

RTCCF는 역할(Role), 작업(Task), 맥락(Context), 제약(Constraints), 형식(Format)을 확인하는 틀이에요. 정해진 주문처럼 쓰기보다는, 답을 작성하는 데 부족한 정보가 없는지 살피는 체크리스트로 활용하면 좋습니다.

원문의 방콕 여행 요청은 가족 구성과 원하는 출력 형식이 구체적이지만, 이동 수단은 대중교통인데 제약은 “차로 30분 이내”여서 기준이 서로 달랐어요. 이를 대중교통 이동 기준으로 맞춘 프롬프트 예시입니다. 실제 여행 일정을 생성하거나 교통 시간을 확인한 결과는 아닙니다.

```text
역할: 가족 여행 동선을 설명하는 여행 안내자의 관점에서 답해 주세요.

작업: 가족이 식도락을 즐길 수 있는 방콕 2박 3일 일정을 제안해 주세요.

맥락:
- 여행자는 60대 두 명과 30대 두 명, 총 네 명입니다.
- 대중교통을 이용합니다.
- 숙소는 지하철역 가까운 호텔을 가정하되, 위치가 필요하면 확인해 주세요.
- 항공편 이동 시간은 일정에서 제외합니다.

제약:
- 방콕 시내의 가족이 함께 방문할 수 있는 장소를 골라 주세요.
- 장소 간 대중교통 이동은 가급적 30분 이내를 목표로 해 주세요.
- 도보와 환승 부담을 함께 고려해 주세요.
- 확인하지 못한 이동 시간이나 영업 정보는 추정 또는 확인 필요로 표시해 주세요.

형식:
- 날짜별 오전, 점심, 오후, 저녁 순서의 마크다운 일정으로 작성해 주세요.
- 각 날짜 하단에 이동 팁을 두 줄로 요약해 주세요.
```

역할을 “20년 차 전문가”라고 적는 것은 문체와 관점을 유도하는 설정이지 사실 확인을 대신하는 근거는 아니에요. 원문에 언급된 프롬프트 보안도 이 구분과 연결됩니다. 문서나 웹페이지 안에 “앞의 지시를 무시하라”는 문장이 있어도 그것은 처리할 자료이지 실행 권한을 가진 지시가 아닙니다. 외부 자료와 시스템 지시의 경계를 구분하고, 비밀 정보나 도구 권한을 불필요하게 노출하지 않아야 해요.

## 3. Pandas와 NumPy는 데이터의 서로 다른 면을 다뤄요

프롬프트에 맥락이 필요하듯 머신러닝 모델에도 적절한 입력 데이터가 필요합니다. 표를 읽고, 잘못된 값을 확인하고, 계산하기 좋은 구조로 바꾸는 과정에서 Pandas와 NumPy를 함께 사용해요.

Pandas는 CSV·SQL 등에서 읽은 자료를 열 이름과 인덱스가 있는 표로 다루기 편합니다. 여러 자료를 병합하고, 결측값을 확인하고, 조건에 맞는 행이나 필요한 열을 선택할 수 있어요. NumPy는 일정한 자료형의 배열과 벡터화 연산을 제공해 수치 계산에 자주 사용됩니다. 이미지의 픽셀 배열, 신호 처리, 거리 계산과 행렬 연산도 연결되는 예입니다.

| 작업 | 자연스럽게 연결되는 도구 |
| --- | --- |
| 자료 읽기·병합·정리 | `pd.read_csv()`, 표 병합, 결측값 처리 |
| 조건 선택·그룹별 요약 | DataFrame 필터와 `groupby()` |
| 배열 연산·행렬곱 | NumPy 배열과 벡터화 연산 |
| 모델 입력 준비 | 모델이 요구하는 DataFrame, NumPy 배열 또는 텐서 |

> 정정: Pandas→NumPy→모델이 언제나 필수 순서는 아닙니다. Pandas에도 수치 계산 기능이 있고, 모델이 DataFrame을 직접 받을 수도 있어요. NumPy 자체가 일반적인 GPU 텐서 라이브러리는 아니며, PyTorch 같은 도구는 별도의 텐서 체계를 사용합니다.

## 4. 배열의 자료형과 모양을 먼저 확인하기

Python 리스트는 서로 다른 객체에 대한 참조를 담을 수 있어요. NumPy의 `ndarray`는 하나의 `dtype`에 맞춘 배열을 제공하며, 수치 배열에서는 일정한 원소 크기와 최적화된 연산을 활용할 수 있습니다. `np.int64`, `np.float64`처럼 자료형을 명시하거나 값에 따라 추론하도록 둘 수 있어요.

```python
import numpy as np

python_list = [10, 20, 30]
numpy_array = np.array([10, 20, 30], dtype=np.int64)
print(python_list * 2)
print(numpy_array * 2)
print(numpy_array.dtype, numpy_array.shape)
```

리스트에 `* 2`를 적용하면 원소 구성이 반복되지만, 수치 배열에서는 각 원소를 곱해요. 이런 벡터화 연산은 Python 반복문을 직접 쓰는 부담을 줄일 수 있습니다. “동시에 계산한다”는 표현은 반드시 여러 CPU 코어를 사용한다는 뜻은 아니에요.

> 정정: NumPy 배열은 숫자만 담는 것이 아닙니다. 문자열, 불리언, 구조화 dtype, `object` dtype도 있어요. 슬라이스로 만든 뷰 등은 비연속 메모리 배치를 가질 수 있으므로 모든 배열이 항상 연속적이라는 설명도 제한적입니다. 배열 인덱싱의 가능성과 속도를 단순히 연속 배치 하나로만 설명하지 않는 편이 좋아요.

비트는 이진 정보를 표현하는 단위이고, 바이트는 8비트입니다. 고정 폭 부호 있는 정수는 흔히 2의 보수 표현을 사용해요. n비트 정수의 범위는 `-2**(n-1)`부터 `2**(n-1)-1`까지입니다. 원문의 하한에서 빠진 음수 부호를 바로잡았습니다. Python의 일반 `int`와 NumPy의 고정 폭 정수는 표현 범위와 오버플로 동작도 구분해야 해요.

1차원 배열은 벡터, 2차원 배열은 행렬을 표현하는 데 쓸 수 있습니다. 텐서는 3차원 이상만을 뜻하는 것이 아니라 스칼라·벡터·행렬을 포함해 더 일반적인 개념이에요.

## 5. 슬라이싱, 모양 변경, 축의 의미 연결하기

아래 `matrix`는 원문에 빠진 초기값을 보충한 설명용 배열입니다. 행과 열을 구분해 접근하는 연습에 사용해요.

```python
import numpy as np

matrix = np.arange(1, 13).reshape(3, 4)
print(matrix[0, 2])
print(matrix[0:2, 1:3])
print(matrix[:, 0])
print(matrix[1:, :2])

arr = np.array([1, 2, 3, 4, 5, 6])
grid = arr.reshape(2, 3)
auto_grid = arr.reshape(3, -1)
flat_arr = grid.flatten()
print(grid, auto_grid, flat_arr, sep="\n")
```

슬라이스의 끝 인덱스는 포함하지 않아요. `matrix[1:, :2]`는 두 번째 행부터 마지막 행까지, 열은 인덱스 0과 1을 선택합니다. `reshape()`는 원소 수를 유지하며 모양을 바꾸므로 새 차원들의 곱이 원소 수와 맞아야 해요. `-1`은 한 차원을 자동 추론하게 하는 값이며 한 번만 사용할 수 있습니다.

`flatten()`은 다차원 배열을 1차원 복사본으로 만듭니다. 2차원에만 쓰는 함수는 아니에요. `reshape()`는 가능한 경우 원본 데이터를 공유하는 뷰를 만들지만 필요하면 복사할 수도 있습니다.

축을 따라 집계할 때는 “어느 축을 없애는가”를 생각하면 덜 헷갈려요.

```python
import numpy as np

grid = np.array([[1, 2, 3], [4, 5, 6]])
print(grid.sum(axis=0))
print(grid.sum(axis=1))
```

2차원 배열에서 `axis=0`을 합치면 행 방향을 줄여 각 열의 합이 남습니다. `axis=1`을 합치면 열 방향을 줄여 각 행의 합이 남아요. 원문의 “행 기준, 열 기준”이라는 말만 외우기보다 결과의 모양까지 확인하는 편이 정확합니다.

## 6. 브로드캐스팅과 행렬곱 구분하기

브로드캐스팅은 모양이 다른 배열도 규칙에 맞으면 원소별 연산을 할 수 있게 해 줍니다. 끝 차원부터 비교해 크기가 같거나 한쪽이 1이면 호환되고, 없는 앞쪽 차원은 1처럼 취급해요.

```python
import numpy as np

mat = np.array([[10, 20, 30], [40, 50, 60]])
vec = np.array([1, 2, 3])
print(mat + vec)
print(mat.transpose())
print(mat.T)

mat1 = np.array([[10, 20], [30, 40]])
mat2 = np.array([[1, 2], [3, 4]])
print(mat1 @ mat2)
print(mat1 * mat2)
```

`mat + vec`는 각 행에 같은 벡터를 더해요. 메모리에 벡터를 실제로 여러 벌 복제해야만 하는 것은 아닙니다. 2차원에서 전치는 행과 열을 바꾸고, `@`는 행렬곱을 수행해요. `*`는 원소별 곱이므로 둘을 구분해야 합니다. 행렬곱은 앞 행렬의 열 수와 뒤 행렬의 행 수가 맞아야 해요. 1차원 배열의 `.T`는 모양을 열벡터로 바꾸지 않는다는 점도 알아 두면 좋습니다.

원문의 배열 생성과 필터링 예제도 함께 정리했습니다.

```python
import numpy as np

arr_a = np.array([1, 2, 3])
arr_z = np.zeros((3, 3))
arr_r = np.arange(0, 10, 2)
shape = arr_a.shape
reshaped = np.arange(10).reshape(2, 5)
flattened = reshaped.flatten()
scaled = arr_a * 2
trig = np.sin(arr_a)
added = arr_a + arr_a
slice_data = arr_r[0:5]
filtered_arr = arr_r[arr_r > 5]
```

`arr_r > 5`는 불리언 배열을 만들고, 이를 인덱스로 사용하면 조건에 맞는 값만 남습니다. `shape`는 메서드가 아닌 속성이므로 괄호를 붙이지 않아요. `np.sin()`의 입력 각도 단위는 라디안입니다.

## 7. Series와 DataFrame으로 표에 의미 붙이기

Series는 인덱스가 있는 1차원 자료 구조이고, DataFrame은 행 인덱스와 열 이름이 있는 2차원 표입니다. 딕셔너리로 DataFrame을 만들면 키는 열 이름이 되고, 각 리스트의 값은 해당 열을 채워요. 리스트 전체가 하나의 행이 되는 것은 아닙니다.

```python
import pandas as pd

scores = pd.Series([90, 85, 88])
s = pd.Series([10, 20], index=["a", "b"])

data = {
    "이름": ["김철수", "김영희", "박민수"],
    "부서": ["개발", "기획", "개발"],
    "급여": [4500, 5200, 4800],
}
df = pd.DataFrame(data)
print(scores)
print(s)
print(df)
df.info()
print(df.describe())
df["bonus"] = df["급여"] * 0.1
df_indexed = df.set_index("이름")
df_restored = df_indexed.reset_index()
```

원문의 “잘못된 입력이면 잘못된 출력이 나온다”는 메모는 탐색적 데이터 분석의 이유와 연결돼요. `df.info()`에서 non-null 개수와 dtype을 보면 결측값이나 예상과 다른 타입을 의심할 수 있습니다. `df.describe()`는 수치 열의 개수, 평균, 표준편차, 사분위수, 최솟값과 최댓값을 요약해요. 기본 수치 요약의 50%는 중앙값입니다. 다만 요약 통계만으로 이상치를 확정하거나 모든 데이터 오류를 찾아낼 수는 없어요.

문자열로 저장된 숫자나 결측값이 보이면 원인을 확인하고 치환·타입 변환 정책을 정합니다. Pandas 버전과 설정에 따라 문자열 dtype이나 메모리 출력이 달라질 수 있어 원문의 `info()` 화면을 이번 실행 결과처럼 복사하지 않았어요.

인덱스 변경은 반환값을 저장해야 합니다. `reset_index()`는 기본적으로 기존 인덱스를 열로 되돌리고, `reset_index(drop=True)`는 그 인덱스 값을 버립니다. 단순히 “숫자로 바꾼다”보다 인덱스 정보를 남길지 버릴지까지 구별해야 해요.

```python
import pandas as pd

df = pd.DataFrame({
    "col1": [1, 2, 3],
    "col2": [4, 5, 6],
    "category": ["A", "A", "B"],
})
loc_selection = df.loc[0:2, "col1"]
iloc_selection = df.iloc[0:2, 0]
mask_filter = df[df["col1"] > 1]
df_indexed = df.set_index("col1")
df_reset = df_indexed.reset_index(drop=True)
```

`loc`는 라벨 기준이고, 이 예제의 `0:2`는 끝 라벨 2를 포함합니다. `iloc`는 위치 기준이므로 끝 위치 2를 제외해요. 같은 숫자를 적어도 의미가 다를 수 있습니다.

시험 점수에서 `axis=0`으로 평균을 구하면 학생 행을 모아 시험 열별 평균을 얻습니다.

```python
import pandas as pd

df = pd.DataFrame({
    "midterm": [80, 95, 70],
    "endterm": [85, 90, 75],
}, index=["김철수", "이영희", "박민수"])
score_means = df.mean(axis=0)
centered = df - score_means
print(score_means)
print(centered)
```

`centered`는 원문의 브로드캐스팅 주제를 연결하기 위해 보충한 코드예요. DataFrame에서 Series를 빼면 기본적으로 열 라벨을 맞춰 각 열의 평균을 뺍니다. Pandas의 라벨 정렬은 NumPy의 모양 기반 브로드캐스팅과 구별해야 해요.

## 8. 주택 가격 예제에서 전처리의 경계 정하기

원문은 `house_prices.csv`를 읽고 침실 결측값을 중앙값으로 채운 뒤, 면적당 가격을 만들고 입력을 표준화하는 예제입니다. 계산식을 이어 쓰기 전에 어떤 값이 예측 시점에 있는지, 전처리 기준을 어느 데이터에서 배웠는지 확인해야 해요.

> 정정: 원문의 주석은 평균으로 채운다고 했지만 코드는 `median()`이므로 중앙값 대체입니다. `price_per_sqft`는 목표 가격을 이용하므로 가격 예측 입력에 넣으면 타깃 누수가 생깁니다. 원래 예제의 `X`에는 이 열이 없었지만, 그 용도를 탐색용으로 명확히 했어요. 모든 데이터의 평균·표준편차로 전처리한 뒤 평가 데이터를 나누면 평가 정보도 학습 준비에 섞입니다.

아래는 원문의 Pandas→NumPy 연결을 유지하면서 분리 순서와 0 분모 방어를 보완한 설명용 함수예요. 훈련·평가 표를 나누는 과정은 문제에 맞춰 별도로 수행해야 합니다. 무작위·시간순·그룹별 분리 중 무엇이 맞는지는 원문만으로 결정할 수 없어요.

```python
import numpy as np
import pandas as pd


def prepare_house_data(train_df, test_df):
    columns = ["sqft", "bedrooms", "price"]
    train = train_df[columns].copy()
    test = test_df[columns].copy()

    for frame in (train, test):
        for column in columns:
            frame[column] = pd.to_numeric(frame[column], errors="raise")
        if frame["price"].isna().any():
            raise ValueError("목표 가격의 결측값 처리 정책을 먼저 정해 주세요.")
        if frame["sqft"].isna().any() or (frame["sqft"] <= 0).any():
            raise ValueError("면적은 결측값이 없는 양수여야 합니다.")

    bedroom_median = train["bedrooms"].median()
    if pd.isna(bedroom_median):
        raise ValueError("훈련 침실 값이 모두 결측이어서 중앙값을 정할 수 없습니다.")

    for frame in (train, test):
        frame["bedrooms"] = frame["bedrooms"].fillna(bedroom_median)

    # 탐색용 파생 값이며 모델 입력에는 포함하지 않아요.
    price_per_sqft = train["price"] / train["sqft"]
    X_train = train[["sqft", "bedrooms"]].to_numpy(dtype=float)
    X_test = test[["sqft", "bedrooms"]].to_numpy(dtype=float)
    y_train = train["price"].to_numpy(dtype=float)
    y_test = test["price"].to_numpy(dtype=float)

    if not all(np.isfinite(a).all() for a in (X_train, X_test, y_train, y_test)):
        raise ValueError("무한대 또는 결측 수치가 남아 있습니다.")

    mean = np.mean(X_train, axis=0)
    std = np.std(X_train, axis=0)
    safe_std = np.where(std == 0, 1.0, std)
    X_train_scaled = (X_train - mean) / safe_std
    X_test_scaled = (X_test - mean) / safe_std
    return X_train_scaled, X_test_scaled, y_train, y_test, price_per_sqft


# 원문 파일을 읽는 단계예요. 이 파일은 별도로 준비해야 합니다.
# df = pd.read_csv("house_prices.csv")
# 문제에 맞게 train_df와 test_df를 분리한 뒤 함수를 호출하세요.
```

표준화는 훈련 데이터에서 구한 열별 평균과 표준편차를 평가 데이터에도 똑같이 적용합니다. 일정한 값만 가진 열은 표준편차가 0이므로 그대로 나눌 수 없어 위에서는 분모를 1로 바꿨어요. 이런 보완으로도 데이터가 “100% 학습 준비 완료”라고 말할 수는 없습니다. 빈 훈련 집합, 비현실적인 값, 중복·그룹 관계, 누수와 평가 설계 등을 추가로 확인해야 해요. 교차 검증에서는 각 훈련 폴드 안에서 전처리 기준을 구하도록 파이프라인을 구성해야 합니다.
