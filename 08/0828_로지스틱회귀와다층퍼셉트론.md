# 0828 TIL — 로지스틱 회귀에서 다층 퍼셉트론까지

회귀가 집값처럼 연속적인 수치를 예측했다면, 분류는 꽃의 종류처럼 정해진 범주를 고르는 문제예요. 선형 계산을 버리는 것은 아닙니다. 입력과 가중치로 점수를 만든 다음, 점수를 확률로 해석하고 정답 범주와 비교하는 과정이 더해져요.

## 1. 특성 수와 클래스 수를 구분하기

이진 로지스틱 회귀는 먼저 다음 점수를 계산합니다.

$$
z = w_1x_1 + w_2x_2 + b
$$

가중치와 편향은 학습하는 파라미터예요. 이때 `z`는 확률이 아니라 로짓(logit)입니다. 이진 로지스틱 회귀에서는 양성 확률의 로그 오즈에 해당하며, 시그모이드를 거쳐 확률로 바뀝니다.

> 정정: 원문의 “특성이 두 개면 레이블도 두 개”는 잘못된 연결이에요. 특성 수는 입력의 차원이고 클래스 수는 정답의 종류입니다. 여러 특성을 받아도 각 표본의 정답은 하나의 클래스일 수 있어요. 선형식에는 각 특성의 가중치도 빠짐없이 적어야 합니다.

$$
p(y=1\mid x)=\sigma(z)=\frac{1}{1+e^{-z}}
$$

시그모이드는 유한한 입력을 0과 1 사이의 연속적인 값으로 변환해요. 입력을 바로 0 또는 1로 바꾸는 함수는 아닙니다. 양성 확률이 기준 이상이면 양성으로 분류하는데, 흔히 쓰는 `0.5`는 조정 가능한 임계값이에요. 놓치는 비용과 잘못 경고하는 비용이 다르면 기준도 달라질 수 있습니다.

## 2. 확신하면서 틀린 예측을 벌하는 교차엔트로피

이진 분류에서는 binary cross entropy(BCE)를 사용합니다.

$$
L_{\mathrm{BCE}}=-\left[y\log p+(1-y)\log(1-p)\right]
$$

정답이 `1`일 때 양성 확률을 `0.95`로 주면 손실은 약 `0.0513`, `0.05`로 주면 약 `2.9957`이에요. 원문의 두 예시는 자연로그로 다시 계산해 확인했습니다. 이는 모델 학습 결과가 아니라 주어진 확률에 대한 수식 계산입니다.

정답에 높은 확률을 주면 손실이 작고, 정답에 거의 0의 확률을 주면 손실이 커져요. 여기서 말하는 손실의 “벌점”은 예측과 정답의 불일치에 대한 것이며, 릿지·라쏘처럼 파라미터 크기를 억제하는 규제항과는 구분합니다.

## 3. 여러 클래스에는 클래스별 점수와 softmax 사용하기

상호 배타적인 `K`개 클래스에서는 클래스마다 로짓을 만든 뒤 softmax로 정규화할 수 있어요.

$$
z_k=\sum_{j=1}^{p}x_jW_{jk}+b_k,
\qquad
p_k=\frac{e^{z_k}}{\sum_{r=1}^{K}e^{z_r}}
$$

확률들의 합은 1이고, 가장 큰 확률의 클래스를 선택하는 것이 기본적인 `argmax` 예측이에요. 배치 입력을 `(표본 수, 특성 수)`로 놓고 `XW + b`를 계산한다면 가중치는 `(특성 수, 클래스 수)`, 편향은 `(클래스 수,)`입니다. 라이브러리의 저장 방식은 전치되어 있을 수 있어요. 예를 들어 PyTorch `nn.Linear`의 `weight`는 `(출력 수, 입력 수)`입니다.

> 정정: 편향은 특성별이 아니라 출력별이에요. 원문의 “총 파라미터 12개”는 입력이 3개이고 출력이 3개라면 가능하지만, 붓꽃의 4개 특성과 3개 클래스에는 가중치 12개와 편향 3개를 합쳐 **15개**가 필요합니다. 이미지 내용을 읽은 것이 아니라 명시된 차원에 따라 계산한 결과예요.

## 4. 원-핫과 정수 레이블은 손실함수에 맞춰 선택하기

원-핫 인코딩은 범주마다 열을 만들고 해당 열만 `1`로 표시해요. 범주형 입력에 임의의 숫자를 붙여 연속값처럼 처리하면 원하지 않는 순서와 거리 관계를 줄 수 있는데, 원-핫은 그 문제를 피하는 방법입니다.

원문의 과일 예시는 다음과 같이 정리할 수 있어요. 문자열을 그대로 인코더에 넣을 수 있습니다.

```python
import pandas as pd
from sklearn.preprocessing import OneHotEncoder

data = pd.DataFrame({'과일': ['사과', '바나나', '딸기', '바나나', '체리']})
encoder = OneHotEncoder(sparse_output=False)
encoded_data = encoder.fit_transform(data[['과일']])
encoded_df = pd.DataFrame(
    encoded_data,
    columns=encoder.get_feature_names_out(['과일']),
    index=data.index,
)
print(encoder.categories_)
print(encoded_df)
```

원문처럼 출력 배열만 보면 어떤 열이 어떤 과일인지 놓치기 쉬워서 열 이름도 함께 확인하도록 했어요. `sparse_output=False`는 밀집 배열을 반환하라는 옵션이지 “정수만 받고 확률을 계산한다”는 의미가 아닙니다. 범주가 많을수록 열이 늘어나므로 희소 표현이 메모리에 유리할 수 있어요. 이 옵션은 해당 인자를 지원하는 scikit-learn 버전을 전제로 합니다.

| 손실 표현 | 정답 형태 | 출력과의 관계 |
|---|---|---|
| BCE | 이진 정답 `0` 또는 `1` | 양성 확률과 비교해요. 로짓을 직접 받는 API도 있습니다. |
| 범주형 교차엔트로피(CCE) | 원-핫 또는 확률분포형 정답 | 클래스별 확률과 비교해요. |
| 희소 범주형 교차엔트로피 | 정수 클래스 인덱스 | 정답 클래스 위치를 골라 같은 교차엔트로피를 계산해요. |

$$
L_{\mathrm{CCE}}=-\sum_{k=1}^{K}y_k\log p_k
$$

> 정정: 분류 타깃을 항상 원-핫으로 바꿔야 하는 것은 아닙니다. 정수 클래스 인덱스를 받는 분류 손실은 인덱스의 크기를 중요도로 해석하지 않아요. scikit-learn의 `LogisticRegression`은 문자열 타깃도 처리할 수 있습니다. 범주형 입력 인코딩 문제와 타깃 인코딩 문제를 구분해야 해요.

PyTorch의 `nn.CrossEntropyLoss`는 보통 로짓과 정수 타깃을 받습니다. 그 앞에서 softmax를 적용하지 않아요. 어떤 손실이 확률을 받는지 로짓을 받는지 API 계약을 확인하는 것이 먼저입니다.

## 5. 클래스 비율을 유지하며 나누고 모델을 학습하기

한쪽 클래스가 드물면 무작위로 나눈 작은 검증 세트에서 그 클래스가 거의 사라질 수 있어요. `stratify=y`는 분할할 때 클래스 비율을 대체로 유지하도록 도와줍니다.

아래는 원문의 불균형 합성 데이터와 두 단계 분할을 이어 붙이고, 빠진 import·생성자 호출·변수명을 고친 예시입니다. 데이터 자체가 교육용으로 만들어진 것이며 실제 서비스 데이터를 뜻하지 않아요. 스케일러는 훈련 세트에만 맞추도록 추가했습니다.

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.linear_model import LogisticRegression

df = pd.DataFrame({
    'Feature_1': range(1000),
    'Feature_2': range(1000, 2000),
    'Target': [0] * 900 + [1] * 100,
})
X = df[['Feature_1', 'Feature_2']]
y = df['Target']

X_train_tmp, X_test, y_train_tmp, y_test = train_test_split(
    X, y, test_size=0.20, random_state=42, stratify=y
)
X_train, X_val, y_train, y_val = train_test_split(
    X_train_tmp, y_train_tmp,
    test_size=0.25, random_state=42, stratify=y_train_tmp,
)

binary_model = make_pipeline(
    StandardScaler(),
    LogisticRegression(max_iter=1000),
)
binary_model.fit(X_train, y_train)
val_pred = binary_model.predict(X_val)

# 검증을 통한 설정 선택을 마친 뒤 최종 테스트에 사용합니다.
bin_test_pred = binary_model.predict(X_test)
print(bin_test_pred)
```

최종 비율은 훈련 60%, 검증 20%, 테스트 20%예요. 원문의 `binary_model = LogisticRegression`은 클래스 자체를 대입하므로 `LogisticRegression()`으로 객체를 생성하도록 고쳤습니다. `bin_test_pred`와 `bin_test_preds`, `x_bin_train`처럼 섞여 있던 변수명도 통일했어요.

이 예시는 `val_pred`를 만드는 흐름까지 보여 주지만 하이퍼파라미터 탐색이나 평가지표 보고를 구현한 완성된 실험은 아니에요. 또 두 특성이 서로 상수 차이이고 타깃이 행 순서로 만들어져 있으므로 현실적인 분류 성능을 논할 데이터도 아닙니다.

> 정정: 분류라고 항상 `stratify=y`를 쓰는 것은 아니에요. 클래스별 표본 수가 너무 적으면 분할이 불가능할 수 있고, 시계열이나 그룹 데이터는 시간·그룹 경계를 먼저 지켜야 합니다.

## 6. 한 번의 분할에 덜 의존하는 교차검증

K-fold 교차검증은 개발용 데이터를 `K`개 조각으로 나눠 한 조각을 검증용, 나머지를 훈련용으로 번갈아 사용해요. 각 폴드에서 모델을 새로 학습하고 점수의 평균과 변동을 살펴봅니다. 최종 테스트 데이터는 교차검증 밖에 따로 남겨 둬야 해요.

분류에는 `StratifiedKFold`를 고려할 수 있고, 스케일링·결측치 대치도 각 폴드의 훈련 데이터에서 다시 학습합니다. 전체 데이터를 먼저 전처리한 뒤 교차검증하면 검증 정보가 들어갈 수 있으므로 전처리와 모델을 묶은 `Pipeline`이 도움이 됩니다. 교차검증 평균은 최종 테스트 점수를 대체하는 실측 결과가 아니라 모델 선택을 돕는 추정치예요.

## 7. 선형 분류기의 한계를 은닉층으로 확장하기

원문에서 단층 퍼셉트론이라고 부른 구조는 입력이 출력에 직접 연결된 형태예요. 다만 고전적인 퍼셉트론의 계단 함수·학습 규칙과 로지스틱 회귀의 확률 출력·교차엔트로피는 서로 다른 방식이라는 점을 구분합니다.

은닉층을 추가하면 입력을 중간 표현으로 바꾼 뒤 그 표현으로 클래스 점수를 만들 수 있어요.

$$
H=\operatorname{ReLU}(XW_1+b_1),
\qquad Z=HW_2+b_2
$$

층을 더하는 것만으로 비선형성이 생기지는 않아요. 선형 변환만 연이어 적용하면 하나의 선형 변환으로 합칠 수 있기 때문입니다. ReLU 같은 비선형 활성화가 있어야 더 복잡한 결정 경계를 표현할 수 있어요. 은닉층이 있다고 모두 같은 깊이의 DNN인 것도 아니며, MLP는 구조 계열이고 “깊다”는 설명은 층 수와 연결됩니다.

| 구조 | 가중치와 편향을 포함한 파라미터 수 |
|---|---|
| 입력 4 → 출력 3 | `4 × 3 + 3 = 15` |
| 입력 4 → 은닉 4 → 출력 3 | `4 × 4 + 4 + 4 × 3 + 3 = 35` |
| 입력 4 → 은닉 16 → 출력 3 | `4 × 16 + 16 + 16 × 3 + 3 = 131` |
| 입력 3 → 은닉 4 → 출력 3 | `3 × 4 + 4 + 4 × 3 + 3 = 31` |

> 정정: 원문에는 “은닉층 4개” 그림과 `16 × 3 + 3` 계산이 섞여 있어요. 은닉층 4개라면 출력층 가중치는 `4 × 3`이고, `16 × 3`은 은닉층 16개일 때입니다. 위 표는 서로 다른 구조를 분리해 계산했어요.

“한 특성에 가중치를 네 번 곱하나요?”라는 원문 질문은, 입력 4 → 은닉 4를 기준으로 각 입력이 네 은닉 뉴런에 각각 다른 가중치로 연결된다고 이해하면 돼요. 같은 값을 연속 네 번 곱하는 게 아니라, 네 개의 가중합 계산에 참여합니다.

## 8. 동물 분류 예시를 숫자와 가정으로 나누기

원문에는 몸무게·크기·평균수명이라는 세 입력을 네 은닉 뉴런에 넣는 설명이 있어요. 특정 동물 하나의 입력 예시가 `[15kg, 45cm, 12년]`이라고 해서 은닉층 출력을 곧바로 계산할 수는 없습니다. 실제 가중치와 편향이 없기 때문이에요.

원문이 제시한 활성화 전 값 `[-2.5, 4.2, 1.8, -0.8]`을 **가정한 예시**로 받아들이면 ReLU 이후에는 `[0.0, 4.2, 1.8, 0.0]`이 됩니다. 뒤 문단의 `4.6`은 앞의 `4.2`와 일치하도록 고쳤어요. 각 뉴런이 “고양이 수명”이나 “작은 몸무게”를 담당한다는 설명도 학습 결과가 확인된 사실이 아니라 직관을 위한 가정입니다. 일반적으로 뉴런 하나에 그런 의미가 자동으로 배정되지는 않아요.

출력층 로짓을 원문처럼 `[-0.5, 3.8, -1.2]`로 **별도 가정**하면 softmax는 다음과 같습니다. 은닉값에서 이 로짓이 계산됐다는 증거는 없으며, 아래는 주어진 로짓만 이용한 산술 검산이에요.

| 클래스 | 가정한 로짓 | 다시 계산한 softmax 확률 |
|---|---:|---:|
| 고양이 | -0.5 | 약 1.33% |
| 개 | 3.8 | 약 98.01% |
| 코끼리 | -1.2 | 약 0.66% |

> 정정: 원문의 `2.8%`, `96.5%`, `0.7%`는 제시된 로짓에 대한 softmax와 일치하지 않아 위 값으로 고쳤습니다. 가장 큰 점수가 개인 것은 그대로지만, 이는 실제로 동물을 분류한 결과가 아닙니다.

가중치와 편향은 활성화가 바뀌는 경계의 위치와 방향, 출력에 기여하는 정도에 관여해요. 비선형 활성화 없이 `weight + bias`만으로 결정 경계가 휘어진다고 표현하지는 않습니다.
