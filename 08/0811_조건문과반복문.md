# 0811 조건문과 반복문

데이터를 모았다면 그다음에는 어떤 데이터를 처리할지 결정해야 해요. 조건문은 실행할 일을 고르고, 반복문은 그 일을 여러 요소에 적용합니다. 같은 처리 흐름을 다시 쓰고 싶을 때는 함수로 묶을 수 있어요.

## 1. 사전과 집합을 다시 살펴보기

사전은 키와 값의 쌍으로 구성됩니다. `data[key]`는 키에 연결된 값을 읽고, 키가 없으면 `KeyError`를 발생시켜요. 예외를 처리하지 않으면 실행 흐름이 중단될 수 있습니다. 값이 없을 때 사용할 기본값을 정하고 싶다면 `data.get(key, default)`를 사용해요. 기본값을 생략하면 `None`을 반환합니다.

> 바로잡기: 원문의 “대괄호 인덱스로 순서 조회”는 사전에는 맞지 않아요. `data[0]`은 첫 번째 항목이 아니라 키 `0`을 조회합니다. 사전이 삽입 순서를 보존한다는 것과 위치 인덱스로 접근한다는 것은 다른 이야기예요.

`keys()`, `values()`, `items()`는 각각 키, 값, `(키, 값)` 쌍을 순회할 수 있는 뷰를 반환해요. `items()` 전체가 튜플 하나인 것은 아니며, 순회할 때 각 항목이 튜플입니다. 뷰는 원본 사전의 변경을 반영하므로 고정된 목록이 필요하면 `list(data.items())`처럼 변환할 수 있어요.

집합은 중복을 허용하지 않고 인덱스로 접근할 수 없어요. 리스트의 요소가 해시 가능하다면 `set(values)`로 중복을 제거할 수 있습니다. 다만 원래 리스트의 순서를 유지하는 방법은 아니에요. `set()`은 리스트의 메서드가 아니라 집합을 만드는 내장 타입 호출입니다.

## 2. 조건에 따라 실행 경로 나누기

`if 조건:` 아래에는 조건이 참일 때 실행할 코드를 들여 써요. 조건이 거짓일 때 다른 일을 해야 한다면 `else:`를 같은 깊이에 배치합니다. 여러 선택지가 있다면 `elif`를 이어 붙일 수 있어요.

한 `if`–`elif`–`else` 묶음은 처음 참인 분기만 실행합니다. 원문에서 논리 오류의 가능성을 지적한 부분은 이 동작 자체가 오류라는 뜻이 아니라, 넓은 조건을 먼저 배치하면 뒤의 더 구체적인 조건에 도달하지 못할 수 있다는 뜻이에요. 여러 조건을 각각 실행해야 한다면 독립된 `if` 문이 필요합니다.

콜론과 들여쓰기는 장식이 아니라 문법이에요. 블록 본문이 필요한데 들여쓰기하지 않으면 `IndentationError`가 발생할 수 있습니다. 이미 중첩된 코드 안에 있다면 `else`도 그에 대응하는 `if`와 같은 깊이에 맞춰야 해요.

중첩 조건문은 `if` 안에서 다시 `if`로 판단하는 방식입니다. 두 조건을 모두 만족해야 한다면 `and`, 둘 중 하나만 만족해도 된다면 `or`로 합칠 수 있어요. 다만 각 단계에서 따로 처리할 일이 있다면 중첩 구조를 유지하는 편이 의미를 더 잘 드러냅니다.

## 3. 반복의 범위와 종료 조건 정하기

| 문법 | 역할 |
| --- | --- |
| `for item in iterable` | 이터러블에서 요소를 하나씩 꺼내 처리해요. |
| `range(stop)` | 0부터 종료값 직전까지의 정수 범위를 나타내요. |
| `range(start, stop, step)` | 시작값, 포함하지 않는 종료값, 증감 간격을 정해요. `step`은 0일 수 없어요. |
| `while condition` | 조건이 참인 동안 본문을 반복해요. |
| `break` | 가장 가까운 반복문을 종료해요. |
| `continue` | 현재 회차의 나머지를 건너뛰고 다음 회차로 진행해요. |

> 바로잡기: `for`가 반드시 횟수를 미리 아는 반복문인 것은 아니에요. 이터러블을 순회하는 문법이며, 횟수 중심으로 반복할 때 `range()`를 자주 사용합니다. `continue`도 반복 전체를 처음부터 다시 시작하는 명령은 아니에요.

`while`은 조건에 영향을 주는 값이 바뀌지 않으면 끝나지 않을 수 있어요. 종료가 필요한 프로그램에는 조건 갱신이나 `break` 경로를 마련해야 합니다. 계속 실행되는 서비스처럼 의도적인 무한 반복도 있지만, 이 경우에도 종료·취소 방법을 설계해야 해요.

## 4. 반복 결과를 모으고 함수로 재사용하기

리스트 컴프리헨션은 이터러블의 요소를 가공해 새 리스트를 만드는 표현식이에요. 원문의 형식을 마크다운과 파이썬 문법에 맞춰 정리하면 다음과 같습니다. `expression`, `item`, `iterable`은 실제 값이나 식으로 바꿔야 하는 설명용 자리표시자예요.

```text
new_list = [expression for item in iterable]
```

반복해서 사용할 처리를 이름 붙여 묶은 것이 함수입니다. 원문은 입력·처리·출력의 흐름과 `y = 2 * x + 1`이라는 관계로 함수를 설명해요. 입력을 받아 계산하고 결과를 돌려주는 과정을 떠올리면 이해하기 편합니다. 다만 파이썬 함수가 반드시 인수를 받거나 화면에 출력해야 하는 것은 아니에요. `return`으로 값을 돌려주는 것과 `print()`로 표시하는 것도 구분해야 합니다.

## 5. 기록 범위와 출처

사전·집합 복습, 조건 분기, 중첩 조건, `for`·`while`, `break`·`continue`, 무한 반복, 리스트 컴프리헨션, 함수의 입력·처리·출력을 반영했어요. “종합 제어 실습”, “데이터필터링”은 제목만 있고, 함수 구현은 “VS Code 참조”만 있어 실습 코드를 복원하지 않았습니다.

완성된 실행 코드가 없는 날짜예요. 위 형식은 설명용이며 실행 또는 문법 검사 통과를 주장하지 않습니다.
